Yeh Code Kya Hai:

Yeh aik Next.js / React client component hai jo Spline 3D design tool se export ki gayi interactive 3D WebGL scene ko load karta hai.

  • Dynamic Import: Server Side Rendering (SSR) error se bachne ke liye Spline ko browser par dynamically import karta hai.
  • Responsive Math: ResizeObserver ke zariye container width dekh kar scale() calculate karta hai takay har screen par fit rahay.
  • 15% Cropping: Scene ke upar/neechay se 15% hissa crop karta hai takay extra margins ya watermark chup jayein.

💡 Interactive Tips

  • 🖱️ Left Click + Drag: 3D Model ko kisi bhi direction mein rotate karein.
  • 📜 Scroll Wheel: Zoom in aur Zoom out karein.
  • 🖐️ Right Click + Drag: Model ko pan / move karein.
  • 👆 Hover: Agar scene mein hover effects hain to mouse cursor se react kare ga.

📦 React / Next.js Setup
